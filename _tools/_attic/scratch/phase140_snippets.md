## 5.45 一段规格**重述**了一段我们已经在跑的东西时，七件事（Phase 140）

操作员贴来一整份规格（状态块 + 公式），里面**既有新东西，也有我们已经跑着的东西被重述了一遍**。
**重述比新东西难**：新东西你会去查，重述的你会**点头**。

**第一件 —— 逐行列表，并且把"旧"标出来。**
一张三列表：**他写的 / 控制台里成了什么 / 新还是旧**。这一轮十行里**七行是旧的**，
而"有七行我不需要动"这个结论**只有在列出来之后才有证据**（不列表就只能靠记忆，
而记忆不会告诉你它漏了哪一行）。这也是 §0.31 ⑤ 那句"**哪几条既有的规则对它生效了**"的操作形态。

**第二件 —— 同一个字母在两块里可以是**两个量**。**
他这一份里 `s` 出现两次：热那块 `s = {T < 5600: 0, …}`（**0 基的行**，有第 0 行），
压力那块 `p_base = {s == 1: 110, …}`（**没有 0**，只能是 latch 的状态）。
**定案的不是哪一块看起来更顺，是"哪个键有独立来源"**：
`110/350/800` 就是 `STATE_GAIN`（`calculation.luau` 那一行 **加** 我们 `Config`，两个来源）。
然后**驱动"能把它俩分开的那一拍"**：`T = 12000` 时行是 1，压力表给 500，行的拼法是 −130。
**两份读法必须能在某一拍上给出不同的数**，否则判据证明不了它区分了两者（§0.20 ②）。

**第三件 —— 下标约定可能有三层，而**一句注释**能定案。**
`passive[s+1]`：列表 1 基（Lua）＋ `s` 是 0 基的行 ＝ 我们的 `[row]`。
**别自己选**：他那一行自己的注释写着「状态 1 = −400，状态 2 = −422」，
而按另一种读法状态 1 会是 −422 —— **矛盾的是那个读法，不是他**。
定案写进注释，并且**把被否掉的那一种也写出来**（下一次有人还会想到它）。

**第四件 —— 退役的形状进注释，不进 diff，并且配一条把它放回去的突变。**
`ACTIVE = {…}` 那四行、`PASSIVE` 那张旧表**留在文件里**，理由写在旁边。§0.34 ④：
**一条只在有人记得时才遵守的规矩，早就被忘过一次。**

**第五件 —— 每一项都问"它乘在**哪一层**"。**
这一轮三处变化里有**两处是同一种**：`passive` **移出**关闸（门在 `pure_cbl` 里面），
`p_mult` **只乘** `pure_cbl`。**同一个常数、同一个分支，位置一挪就是另一条规则**，
而在盘上两者的 diff **长得一样**（都是把一个项从括号里挪出去）。
所以判据要问的是"**这一项在不在那个乘法/那道门里面**"，不是"这一项在不在"。

**第六件 —— 重述的那一块，判据拿**他的字面量**驱动。**
压力那四行不是"两处都在"就算对上：检查器**用他写的 `110/350/800`、`0.01/0.0075/0.005`、`60`
自己算一遍**，再和这台控制台的 `Sim.terms()` 比。**两份拼法互相比较**，
"两处都在"和"两处都对"才会分开。
**顺带一条时刻**：压力那一行读的是**这一拍结束时**的温度（`Engine.luau` 的顺序），
所以他自己那个状态块驱动出来是 **136.835 而不是 140** —— **两个时刻，不是一个错**（§0.27 ②）。

**第七件 —— 文档里每一个被引用的数，问它**来自哪一次读数**。**
这一轮翻出的那个 `79 / 5`：旁边的 `84` 是量的，**这两个不是** ——
它们**加起来正好等于 84**、**正好落在该落的那句话里**、**已经抄进三份文档**，
而**能试的判据全试过只出一种拆分（62 / 22）**。
**一个数被量过，不代表它旁边那个也被量过。**
处理规矩照旧：**原文保留 + 当日更正 + 写明哪一半是量的**（§0.14 / §0.29 / §0.34 ②）。

**两条命令**（这一轮的判定，两个数都是新的）：

```bash
python -X utf8 luau-windows/core_model_check.py     # 232 checks, 0 failed   (原 201)
python -X utf8 luau-windows/core_model_mutants.py   # 28 mutants, 0 survived (原 23)
```

**新加的 5 条突变**里有两条是"把旧形状放回去"型的（`passive` 回到关闸后面、
行 1 与行 2 的常数对调）—— **一条规格改过一次之后，最该有牙的突变是"改回上一版"那个。**
